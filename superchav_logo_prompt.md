### Why these choices

| Element | Reasoning |
|---|---|
| **Combination mark** | Most versatile for clothing — works as a chest print, embroidery patch, or woven label |
| **Check pattern symbol** | Instantly reads as chav culture via the Burberry aesthetic; using tan/black/red/white (not the trademarked exact check) captures the reference legally distinct |
| **Thick, flat lines** | Essential for embroidery — thin lines blur; flat vector prints cleanly on jersey, fleece, and caps |
| **Ultra-bold sans-serif all-caps** | Aggressive, authoritative, reads at a distance — standard for streetwear and football casual culture |
| **Horizontal layout** | Fits the natural rectangle of a chest or sleeve placement; scales down to a woven label or up to a back print |
| **Transparent background** | Necessary for real production — print shops and embroidery digitizers need the isolated artwork |
| **Tan + black + red + white** | Tan/camel is the cultural shorthand (Burberry check); black adds aggression; red adds energy; white provides contrast for embroidery stitch-outs |

### What to expect

ChatGPT Image 2.0 should produce a flat vector combination mark: a check-pattern square badge beside "SUPERCHAV" in heavy block letters. Expect clean, bold geometry. The check pattern will be a stylised interpretation — not an exact Burberry clone, but clearly referencing that visual language.

### Next steps / iteration

1. If the check pattern is too busy for your taste, ask for a simplified version: *"Same prompt, but the check pattern symbol is simplified to just 4 large check squares forming a single bold block"*
2. If you want a different layout (stacked or centred), change just that one variable
3. After generation, a designer should vectorise the result in Illustrator for embroidery digitisation and screen-print separations

### Limitation reminder

ChatGPT cannot reproduce trademarked patterns exactly — the check will be a unique interpretation. For trademark registration or production-ready artwork, have a designer clean up the vector paths.
